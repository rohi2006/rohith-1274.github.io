RISC-V Processor

Designed and implemented Single-Cycle, Multi-Cycle, and 5-Stage Pipelined RISC-V processors in Verilog HDL based on Harris & Harris architecture. Implemented hazard detection, data forwarding, stalling, and branch handling for the pipelined variant. Verified via Vivado and Icarus Verilog.

FPGA · Protocol

UART Protocol on Basys-3

Implemented a UART protocol at 9600 baud rate on a Basys-3 FPGA board. Data is serialized via shift registers, transmitted, and deserialized at the receiver with button debouncing. Output displayed on both Basys-3 LEDs and TeraTerm serial terminal.
